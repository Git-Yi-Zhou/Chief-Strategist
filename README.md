# Chief Strategist（首席谋士）

> **用单旗舰模型 Test-Time Compute Scaling 打造“一人内阁”，以可控 Token 燃烧换取更广、更深、更远、更有新意的战略破局推演。**

`Chief Strategist` 是一个基于 **Antigravity 原生 Swarm** 构建的纯零依赖（Zero-Dependency）Agentic DeepThink 插件。当你的主力对话模型显著强于其他备选异构模型时，强行混编多模型往往会导致严重的“低智短板污染”与“均值回归”；本插件彻底摒弃多模型议会模式，转而让当前最强的旗舰模型化身**首席谋士（Strategist）**，动态编排多个**满血同源、认知正交**的思维分身，辅以黑板交叉猎杀、思维树热分叉（`fork`）与隔离分支 PoC 实测（`workspace: "branch"`），在无人值守的心流推演后交付一篇主见鲜明的《首席谋士策论》。

## 核心机制设计

### 1. 反同源坍缩：六大正交认知算子
同源模型分身如果只分“岗位头衔”极易唱双簧。谋士按认知算子而非行政岗位布阵：
1. **异轨先验探子（Orthogonal Explorer）** —— 成对注入彼此互斥的公理前提或跨学科透镜，强行撑开搜索广度（**求广**）。
2. **禁忌破壁奇兵（Taboo Breaker）** —— 简报中明令封禁前 2–3 种常规教科书解法，逼迫模型绕过平庸局部最优（**求新**）。
3. **第一性原理深潜者（First-Principles Driller）** —— 剥离惯例与表面抽象，下钻至物理/数学/代码底层边界与沙盒演算（**求深**）。
4. **事前验尸与多阶博弈官（Pre-Mortem Simulator）** —— 锚定 12–24 个月后失败场景逆推死因，预判二阶反噬与预警绊线（**求远**）。
5. **铁血证伪官（Adversarial Falsifier）** —— 只攻击不附和，专找看似完美共识中最脆弱的隐含假设与反例（**求真**）。
6. **隔离分支实证官（Branch PoC Experimentalist）** —— 挂载 `workspace: "branch"` 在独立克隆区写原型跑基准测试，以真实数据一锤定音（**求实**）。

### 2. 自适应四步推演漏斗
- **破题立纲与盲探发车**：自主按复杂度定规模（3–8 人），开启完整 Swarm 面板（含 `narrator` 与 `monitor`），强约束首轮分身独立盲探防跟风锚定。
- **核心矛盾猎杀**：提炼 1–3 个决定全局的 Cruxes，在黑板直接引用 `#seq` 序号展开短兵相接的交叉证伪与 PoC 实测。
- **果断剪枝与热分叉**：淘汰被击穿分支（`kill`），对高潜枝干利用 Swarm 原生 `fork` 克隆温热上下文多路深挖到底。
- **清场定策**：确认所有 `branch` 临时分支彻底销毁且主工作区零污染后，由谋士行使独断裁断权，通过 Artifact 交付完整的《首席谋士策论》。

## 安装与使用

### 安装部署
将本仓库部署至 Antigravity 全局插件目录 `~/.gemini/config/plugins/chief-strategist/`（Windows 为 `C:\Users\<用户名>\.gemini\config\plugins\chief-strategist\`），Antigravity 将自动热加载，无需外部依赖或重启守护进程。

### 唤醒口令速查
日常普通对话完全静默不介入；当遇到值得烧 Token 深思的硬核议题时，只需自然语言唤醒：

- **标准自主模式**：
  > `/strategist 请对当前项目的状态管理瓶颈做一次破局推演`
  > `首席谋士：我们要不要自研这套跨进程通信层？帮我算透利弊与远期隐患`
- **极限燃烧模式**（扩张算子阵列 + 强制 PoC 实测 + 多轮 `fork` 深挖）：
  > `开谋士，极限燃烧模式：不计 Token 成本帮我彻底重思这套分布式缓存架构`
- **轻量速推模式**（2–3 席精锐算子快筛）：
  > `一人内阁轻量推演一下这个 API 拆分的反直觉隐患`
- **谋后直接施工**（默认“谋断分离”等你拍板；仅当你明确下令时定策后自动进入执行）：
  > `首席谋士：把这套调度算法想透后直接落地施工`
