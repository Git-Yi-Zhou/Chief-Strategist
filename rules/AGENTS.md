# 首席谋士（Chief Strategist）按需激活说明

仅当用户明确输入 `/strategist`、“首席谋士”、“开谋士”、“谋士深思”、“一人内阁”，或在指令开头以“谋士：”明确唤醒深度战略推演时，先读取 `strategist` 技能说明并严格按其中规程执行。

边界与隔离铁律：
- 日常普通对话、单一执行型编码任务，或用户触发 `/cabinet` / “开内阁”（属 `paseo-cabinet` 异构内阁议事）时，**不启用**本插件。
- 一旦进入首席谋士模式，全程仅使用 Antigravity 原生 `swarm` 体系调度满血同源分身，**严禁**调用 `paseo-cabinet` 或 `paseo-orchestrator` 工具链。
